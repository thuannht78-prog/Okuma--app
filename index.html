Quản lý setup

Mỗi setup là một tệp PET của IGF-L: phôi và đồ gá (BLANK/SETUP), bảng dao (TOOL DATA), biên dạng (TURNING SHAPE), quyết định (PROCESS DECIDE), sửa nguyên công (PROCESS EDIT), kiểm tra (PROCESS TEST) và tạo chương trình (PROGRAM CREATE). Dữ liệu lưu trên máy này.

Chưa có setup. Bấm Tạo setup mới để bắt đầu một sản phẩm.

    Quy trình IGF

    Chưa mở setup. Vào Setup để tạo mới, mở hoặc sao chép một sản phẩm.

    Quy trình IGF-L (7 bước trong tệp PET)

    Sách hướng dẫn LE32-239-R1 (5/2023) và sách tham chiếu LE32-238-R1 (8/2023). Số trang là trang in.

    1. Phôi và đồ gá (BLANK/SETUP) — vật liệu, ROUND BAR / FREE / UNIFORM STOCK, OD, LENGTH, BLANK ID, mốc Z, G50; tờ 1 SPINDLE (kẹp, chấu); tờ CENTER. LE32-239 P-17–19, LE32-238 P-84–95.
    2. Bảng dao (TOOL DATA) — loại dao, TOOL ANGLE, EDGE ANGLE, PROCESS KIND, T No., OFFSET No. Ví dụ sách: T1 thô 80°/5, T2 tinh 55°/3. LE32-239 P-13.
    3. Biên dạng tiện (TURNING SHAPE) — START PT SX/SZ, DEF. DIR., rồi FACE, TAPER, LONG, C-CHF, R-CHF, JUMP. LE32-239 P-20–38, LE32-238 P-96.
    4. Quyết định (PROCESS DECIDE) — chọn PATTERN rồi F7 EXECUTE. Bốn sổ quy tắc LE32-239 P-40–41. LE32-239 P-39–44, LE32-238 P-170.
    5. Sửa nguyên công (PROCESS EDIT) — chèn, xóa, đảo, sao chép, sửa chế độ cắt. LE32-239 P-45–46, LE32-238 P-210.
    6. Kiểm tra (PROCESS TEST) — chạy hoạt hình đường dao. LE32-239 P-47–48, LE32-238 P-201.
    7. Tạo chương trình (PROGRAM CREATE) — FILE NAME (16 ký tự), DDT FILE, PROGRAM NAME (O + 8 ký tự), rồi tải .MIN. LE32-239 P-49–50, LE32-238 P-299.

    Màn Quản lý setup tương ứng thao tác tệp: F3 NEW FILE, F2 EDIT, F5 COPY, F6 RENAME, F7 DELETE (LE32-239 P-14–16). Dao đăng ký trên NC trước khi mở tệp (mục 3-2). Ụ tiến/lùi là nguyên công TS ADVANCE / TS RETRACT (LE32-238 P-368).
